# Kinbits Beta

Kinbits beta builds for personal testing through SideStore and AltStore Classic.

## Requirements
- iPhone running iOS 17 or later
- SideStore or AltStore Classic
- Your own Apple Account for free signing

## Important
- Free Apple signing normally requires refreshing the app before the 7-day provisioning period expires
- Update Kinbits over your existing installation
- Do not delete Kinbits before updating unless specifically instructed, because deleting the app can remove local pet data
